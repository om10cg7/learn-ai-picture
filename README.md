# learn-ai-picture

写真・画像編集系の Instagram 投稿（リール／カルーセル）を要約した勉強ノート集。
Muse の「写真」チャットで要約した内容をまとめたもの。

📋 画像付き一覧は [index.html](index.html)（各カードに画像・元ネタURL・ノートへのリンク付き）。

- 元投稿へのリンクは各ノートに記載
- 数値・HEXコード等は、目視確認したものはその旨を明記し、自動解析のみのものは参考値として扱う
- commit / push は本人の指示があった時だけ行う
