# 写真に日光を足してシネマティックに

- 投稿者: @haphann96（Phan Thanh Hà、ベトナム）
- 元投稿: https://www.instagram.com/reel/DdGgc40TfF8/
- テーマ: 「How I add sunlight to make my photos more cinematic」

真上からの構図：横断歩道の上の男性ランナー（白タンクトップ、黒ショーツ、赤キャップ）。平坦な昼光 → ゴールデンアワーの見た目＋長い影。セリフなし。

全設定は作者本人の固定／先頭コメントから取得（2026-11-02）:
- Mask 1 Model: Exposure +0.3 / Contrast +50 / Saturation +5
- Mask 2 Background: Exposure +1.75 / Contrast +10 / Temperature +62 / Hue -8
- Mask 3 Linear gradient: Exposure -2.5 / Temperature +78 / Tint -44 / Hue -140
- Mask 4 Rimlight（動画内表記は Brush）: Exposure +0.3 / Temperature +5 / Saturation +30

影は Photoshop の別ステップ:
- Pen Tool（P）で光の方向に沿って長い影を描く → 黒／ダークグレーで塗る → Ctrl+U で彩度 -100 → Ctrl+T で伸ばし／歪める → 描画モード Multiply

コメント欄は賛否両論（「fake」「写真とは言えない」「光とグラデーションが合っていない」「その硬い影は Lightroom では作っていない」等。最後の指摘は正確で、影は Photoshop で描いている）。
