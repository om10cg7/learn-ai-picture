# 色を集めたムードボード4種

- 投稿者: @tanco_camera（丹子tanco）
- 元投稿: https://www.instagram.com/reel/DfN6ufBT2na/
- キャプション: 「色を集めて作品を作っています！」
- 確認方法: ブラウザ目視で確認済み（2026-11-02）。各ボード中央に縦5色のHEX＋写真4枚、音楽は穏やかなソロピアノ

1. 深い青／水中: #244B6D / #1A4A57 / #486F76 / #092E3E / #122931
   - 光芒の中の魚群、淡い紫陽花のような花、濡れた葉／紫陽花のクローズアップ、光るクラゲ
2. ゴールド／黒猫: #BC8F37 / #C2AF8B / #816C3D / #26393B / #162429
   - 黄色い花のある六角形ミラー、金色の目の黒猫、黄色い小花のある深緑の葉、楽譜と黄色い花と陽の影
3. 空／海／夕景: #3D4256 / #605A66 / #79575B / #293C4D / #182836
   - 夜のボケとシルエット、曇り空の鳥1羽、橋と山のある沿岸の湾、夕景の水面と暗い雲
   - （自動解析の #665A66 / #182636 は誤り）
4. トマト: #C94324 / #D0683E / #254447 / #1B2D33 / #43574B
   - 泡のある水中のトマト、フォークに刺した半切りのミニトマト、グラスの中で弾けるトマト、ボケのある大きなトマト
