# Photoshopで身長を伸ばす

- 投稿者: @gfx.om
- 元投稿: https://www.instagram.com/reel/Det5FXGTnb_/
- 素材: Tom Holland / Zendaya の『Spider-Man: Homecoming』写真
- 確認方法: ブラウザで目視確認済み（2026-11-02）

手順:
1. Object Selection Tool の「Select people」で男性だけを選択
2. 男性を別レイヤー（Layer 1）に分離（レイヤー構成: Layer 1 / Background copy / Background）
3. Select > Modify > Expand… で選択範囲を拡張
4. Layer 1 を隠し、背景側から男性を消して背景を埋める
5. Layer 1 だけを変形。画面で確認できた値: W 100.00% / H 103.02%、途中に W/H 連動 110.40% のフレームがあり、確定時は 100% に戻る

結果: 女性は不変、男性の頭が女性と同じ〜やや上になる。

未確認（フレームで確認できなかった）: Expand の「10px」という値、Content-Aware／Generative Fill のメニュー名、「Free Transform」のメニュー名。
