## 使い方（画像内の HOW TO USE）

プロンプトの先頭にコードを付けると、画像のスタイルやテーマを誘導できる、という形式。ChatGPT の画像モードで、要素の画像をアップロードしてからコードで出力を指定する流れがキャプションに書かれている。

## ライティング9コード（画像の説明文ママ）

| コード | 画像内の説明 |
|---|---|
| `/back light` | Create a dramatic backlit subject.（ドラマチックな逆光） |
| `/side back light` | Add a rim light from the side and back.（側面・背後からのリムライト） |
| `/top light` | Illuminate from above.（真上から照らす） |
| `/side light` | Create depth with side lighting.（サイド光で奥行き） |
| `/front side light` | Add dimension with front-side lighting.（斜め前からの光で立体感） |
| `/rembrandt light` | Create a triangular shadow for depth.（頬に三角の影。綴りは画像ママで Rembrandt の t が1つ落ちている） |
| `/front light` | Evenly light the subject from the front.（正面から均一に） |
| `/butterfly light` | Create a soft, flattering shadow under the nose.（鼻の下に蝶形の影） |
| `/bottom light` | Add a dramatic, edgy effect from below.（下からの光で険のある効果） |

各コードには作例ポートレートと光源配置のダイアグラムが付く。

## 学び・所感

- 中身は写真ライティングの古典（レンブラント、バタフライ等）そのもので、新しいのは「/スラッシュコードをプロンプト先頭に付ける」という呼び出し形式のほう。ChatGPT 画像生成がコードを安定して解釈するかはモデル依存で、通常の英語指定文（Rembrandt lighting 等）と効果がどう違うかは未検証
- 9種のうち実務で効くのは back／side back（リム）／rembrandt／butterfly の4つで、残りは位置の基本バリエーション。24種版の既存ノートと合わせると、ライティング指定の語彙としてはほぼ揃う
