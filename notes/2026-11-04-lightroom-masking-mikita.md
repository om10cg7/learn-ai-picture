# Lightroom マスキング・チュートリアル

- 投稿者: @mikita.yo（Mikita Yo、シネマティック撮影・編集、現在イタリア）
- 元投稿: https://www.instagram.com/p/DfSdnjBDOjV/（img_index=6 指定）
- 形式: カルーセル全12枚。締めは無料マスキングガイド（「Masking」コメントで配布、モバイル／デスクトップ対応）

全体の流れ:
- 表紙：棚田の空撮と夕日の農作業
- 作例1（霧の棚田の丘）：BEFORE → マスク注釈 → AFTER（金色の光）
- 作例2（水の中のサル）：BEFORE → 被写体選択の注釈 → 完成
- 作例3（山の湖）：BEFORE → 明瞭度／グリーン／反射の調整注釈 → AFTER（暖かいトーン）
- 最終枚：夕日の棚田と海で無料ガイドへのCTA

指定スライド（img_index=6、表紙から7枚目、画像内表記「B6」）※目視確認済み:
- 浅い水に座り両手を口元に寄せたサル。背景はぼけた緑の葉、下部は水面
- サル全体にオレンジの太い輪郭＋斜めストライプ＝主体マスク、目と水面に青い楕円・斜線、背景に白い楕円（ヴィネット状）
- 読めた注釈: 右「Subject Selection - Clarity / Color / Isolation」、左中央「Mask - Highlights / Color」、上部 手書き風「Dark / Mask / Color / Shadows」、左下「Vignette - Dark …」（後半は読み取り不可）
- 前後: 6枚目が同じサルの BEFORE、8枚目が完成写真
